# Building Resilient Microservices: A Hands-On Journey Through Distributed Data Patterns

In this interactive workshop, participants will architect and deploy a geographically-redundant event-driven system using containers, bringing the power of modern infrastructure directly to their laptops.

Working with lightweight Docker environments (Kubernetes via kind optional), we will incrementally build a complete distributed data pipeline from scratch. Starting with microservices writing to local databases, you'll implement the outbox pattern to reliably publish events, then master the inbox pattern to consume and process them. The workshop culminates in tackling real-world geo-redundancy challenges as participants connect multiple Kafka clusters across simulated geographic boundaries, applying event aggregation patterns to synchronize data seamlessly.

No Kafka experience required; Just bring a laptop with Docker and your curiosity! All code templates, environments, and solutions are publicly available beforehand, ensuring every participant builds upon a foundation of working code at each step.

What attendees will build:
- Containerized multi-service architecture
- Reliable event publishing and consumption systems
- Cross-cluster data synchronization using aggregation patterns
- Real-time API endpoints exposing synchronized data

Whether you're a developer wanting to master event-driven architecture, a sysadmin exploring platform capabilities, or an architect designing resilient systems, this workshop delivers practical experience with patterns and technologies reshaping modern distributed systems. Leave with a fully functional geo-redundant microservices deployment, and the skills to implement these patterns in production.
